# Screenshots Checklist

This document outlines the screenshots required for the Aptura Tech Solutions
Week 1 Task 1 submission. Capture each screenshot at the specified viewport
width using browser DevTools responsive mode.

---

## Required Screenshots

### 1. Desktop — Full Landing Page
- **Viewport:** 1440 × 900
- **Capture:** Full page scroll from hero to footer
- **Demonstrates:** Hero section, 3D robot scene, marquee, metrics, resume, projects, skills, education, achievements, contact form, footer

### 2. Desktop — Hero Section
- **Viewport:** 1440 × 900
- **Capture:** Above-the-fold hero area
- **Demonstrates:** Name, role, availability, CTA buttons, 3D scene, scroll progress bar, navigation

### 3. Desktop — Projects Section
- **Viewport:** 1440 × 900
- **Capture:** Projects grid area
- **Demonstrates:** 2-column project cards with tech stack tags

### 4. Desktop — Contact Section
- **Viewport:** 1440 × 900
- **Capture:** Contact form and contact details
- **Demonstrates:** Email, phone, location, availability dot, contact form with labels

### 5. Desktop — Owner Login
- **Viewport:** 1440 × 900
- **Capture:** /auth page
- **Demonstrates:** Login card, back button, logo, email input

### 6. Desktop — Owner Inbox
- **Viewport:** 1440 × 900
- **Capture:** /dashboard page (when logged in)
- **Demonstrates:** Header, back/sign-out buttons, message list or empty state

### 7. Mobile — Full Landing Page
- **Viewport:** 375 × 812 (iPhone 14)
- **Capture:** Full page scroll
- **Demonstrates:** Responsive hero, wrapped navigation, stacked sections

### 8. Mobile — Navigation
- **Viewport:** 375 × 812
- **Capture:** Header navigation area
- **Demonstrates:** Wrapped nav links, centered layout

### 9. Mobile — Contact Form
- **Viewport:** 375 × 812
- **Capture:** Contact section
- **Demonstrates:** Stacked form fields, full-width submit button

### 10. Tablet — Landing Page
- **Viewport:** 768 × 1024 (iPad)
- **Capture:** Above-the-fold area
- **Demonstrates:** Tablet-sized layout, 3D scene, navigation

### 11. 404 Page
- **Viewport:** 1440 × 900
- **Capture:** /nonexistent-page
- **Demonstrates:** 404 error page with back-to-portfolio button

### 12. CV Download
- **Viewport:** 1440 × 900
- **Capture:** Resume section with "Download CV" button visible
- **Demonstrates:** CV download button placement

## How to Capture

1. Open the live site: [https://afaqulislam.freebuff.app/](https://afaqulislam.freebuff.app/)
2. Open browser DevTools (F12)
3. Toggle device toolbar (Ctrl+Shift+M)
4. Select the specified viewport width
5. Take a full-page screenshot or specific area screenshot
6. Save with a descriptive filename (e.g., `desktop-hero.png`, `mobile-contact.png`)
